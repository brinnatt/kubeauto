<div class="td-content">
	<h1>Installation</h1>
        <div class="lead">Instructions for installation of Kubernetes cluster and Redis Operator</div>
	
	<h2 id="usage-requirements">Usage Requirements</h2>
<ul>
<li><strong>Kubernetes cluster version &gt; 1.18</strong>
<ul>
<li>All Kubernetes platform are supported like: <a href="https://cloud.google.com/kubernetes-engine/">Google Kubernetes Engine</a>, <a href="https://azure.microsoft.com/en-us/services/kubernetes-service/">Azure Kubernetes Service</a>, <a href="https://aws.amazon.com/eks/">Amazon EKS</a> and <a href="https://github.com/kubernetes/minikube">Minikube</a>.</li>
</ul>
</li>
<li>Redis cluster needs persistence support in Kubernetes cluster</li>
</ul>
<h2 id="supported-container-architectures">Supported Container Architectures</h2>
<p>The following container operating systems and architectures can be utilised with Redis Operaror:</p>
<table>
<thead>
<tr>
<th>OS</th>
<th>Architecture</th>
<th>Support</th>
</tr>
</thead>
<tbody>
