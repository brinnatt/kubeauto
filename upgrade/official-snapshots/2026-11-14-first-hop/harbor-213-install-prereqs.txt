<div 
  class="navbar-item theme-toggle-wrapper"
  x-data="{ 
    theme: 'light',
    init() {
      // Initialize theme from localStorage or system preference
      const savedTheme = localStorage.getItem('harbor-theme');
      const systemPrefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
      this.theme = savedTheme || (systemPrefersDark ? 'dark' : 'light');
      this.applyTheme();
    },
    applyTheme() {
      document.documentElement.setAttribute('data-theme', this.theme);
      localStorage.setItem('harbor-theme', this.theme);
    },
    toggleTheme() {
      this.theme = this.theme === 'light' ? 'dark' : 'light';
      this.applyTheme();
    }
  }"
>
  <button 
    @click="toggleTheme()"
    class="theme-toggle"
    :aria-label="theme === 'light' ? 'Switch to dark mode' : 'Switch to light mode'"

    type="button"

          <p>Harbor can be deployed to a Docker host using Docker Compose, or to a Kubernetes cluster using Helm.</p>
<h3 id="resource-requirement">Resource Requirement</h3>
<p>The table below outlines the minimum and recommended resource requirement for deploying Harbor.</p>
<table>
<thead>
<tr>
<th>Resource</th>
<th>Minimum</th>
<th>Recommended</th>
</tr>
</thead>
<tbody>
<tr>
<td>CPU</td>
<td>2 CPU</td>
<td>4 CPU</td>
</tr>
<tr>
<td>Mem</td>
<td>4 GB</td>
<td>8 GB</td>
</tr>
<tr>
<td>Disk</td>
<td>40 GB</td>
<td>160 GB</td>
</tr>
</tbody>
</table>
<h3 id="software-stack-requirements-compose">Software Stack Requirements Compose</h3>
<p>The following table lists the software versions that must be installed on the target host.</p>
<table>
<thead>
<tr>
<th>Software</th>
<th>Version</th>
<th>Description</th>
</tr>
</thead>
<tbody>
<tr>
<td>Docker Engine</td>
<td>Version &gt; 20.10</td>
<td>
<a href="https://docs.docker.com/engine/install/" target="_blank">Docker Engine Installation</a></td>
</tr>
<tr>
<td>Docker Compose</td>
<td>Docker compose &gt; 2.3</td>
<td>Docker Compose is part of Docker Engine</td>
</tr>
<tr>
<td>OpenSSL</td>
<td>Latest (optional)</td>
<td>Used to generate certificate and keys for Harbor</td>
</tr>
</tbody>
</table>
<h3 id="network-ports">Network ports</h3>
<p>Harbor requires that the following ports be open on the target host.</p>
<table>
<thead>
<tr>
<th>Port</th>
<th>Protocol</th>
<th>Description</th>
</tr>
</thead>
<tbody>
<tr>
<td>443</td>
<td>HTTPS</td>
<td>Harbor portal and core API accept HTTPS requests on this port. You can change this port in the configuration file.</td>
</tr>
<tr>
<td>80</td>
<td>HTTP</td>
<td>Harbor portal and core API accept HTTP requests on this port. You can change this port in the configuration file.</td>
</tr>
</tbody>
</table>
<h2 id="install-harbor-on-kubernetes">Install Harbor on Kubernetes</h2>
<p>To install docker with Helm, see the dedicated repository 
<a href="https://github.com/goharbor/harbor-helm" target="_blank">github.com/goharbor/harbor-helm</a></p>
